## 💻 Sobre o desafio

Criei este repositório para registrar minha evolução resolvendo problemas do [LeetCode](https://leetcode.com/).

A proposta não é apenas acumular exercícios resolvidos.

Quero usar cada problema para melhorar meu raciocínio lógico, entender diferentes estruturas de dados, analisar complexidade e aprender a encontrar soluções mais eficientes.

Pretendo resolver os desafios com frequência e documentar tanto as soluções quanto os aprendizados ao longo do processo.
